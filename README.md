# The Reformation Atlas

Interactive historical atlas of the Protestant Reformation across Europe (1370–1689).

**[Live Demo](https://garridolecca.github.io/reformation-atlas/)**

## Features

- 30+ historical locations with real coordinates across Europe
- 4 color-coded eras: Pre-Reformation, Lutheran, Reformed & Radical, Post-Reformation
- 15 key figures: Wycliffe, Hus, Luther, Calvin, Knox, Zwingli, and more
- Bilingual interface (English / Spanish)
- Interactive ArcGIS map with zoom-based label collision detection
- Timeline panel, figures panel, and detailed bottom sheet navigation
- Mobile-friendly with touch gestures

## Tech Stack

- ArcGIS Maps SDK for JavaScript 5.0
- Calcite Design System
- CartoDB Positron basemap tiles
- Google Fonts (Cinzel + Inter)
- Vanilla JavaScript (ES Modules)

## Getting Started

```bash
npx serve .
```

Then open the local URL in your browser.
